**Findings**

**F1. High (blocking if its log is cited as proof): the candidate planted-bug runner fails on the unmodified script.**
- **Where:** `<F>/runner_parts.py`, in MAIN `run_one`, which `build_planted.py` uses.
- **What I did:** ran its `run_one(source, X, X)` with `old == new`, so the script was unchanged.
- **Result (OBSERVED):** "failed", with 86 failing tests. All of them say `InvalidInput: git could not check the raw transcript (fatal: not a git repository ...)`. With the line `TMPDIR=str(scratch), TEMP=..., TMP=...` removed, the same run is "survived" (green).
- **Cause:** the copy is at `root/participant/skills/x/ingest.py`, so the script treats `root` as the repository. Scratch is `root/tmp`, so every raw file the suite writes sits inside that "repository", which is not a git repo.
- **Effect (INFERRED):**
  - Every planted bug would print KILLED.
  - check_claims' checks 3 and 4 would pass trivially.
  - `final/planted_bugs.py` is not built yet, so this has not run yet.
- **Related gap:** none of the three runners runs the unmodified script as a baseline: runner_parts, the repo's tests/planted_bugs.py, and mutrun.py.
- **Smallest fix:**
  - Make scratch a separate `tempfile.TemporaryDirectory()` outside `root`.
  - Run the unmodified script first, and abort unless it exits 0.

**F2. Medium (the safety-constraint claim in SKILL.md section 10 can be falsely backed): the watchdog can be swallowed.**
- `Stalled(Exception)` raised by SIGALRM is caught by any `except Exception` in the script, and the timer fires only once.
- **OBSERVED:** the planted bug in the last table row passes the whole suite in 41 s.
- That scan grows with the square of the input: 5k, 10k and 20k 'bot' words took 4.4 s, 17.4 s and 69 s. So the suite's 80,000-word cue would take about 18 minutes (extrapolated, INFERRED).
- **Smallest fix:** in `within_seconds`, after `yield`, raise AssertionError if `time.monotonic() - started > limit`. Optionally also derive Stalled from BaseException and catch it in main().

**F3. High (by the review's rubric: a misleading claim; low safety impact): SKILL.md section 11 is out of date.**
- It says "There are 32 tests" (28/1/3) and "85 planted bugs". The file has 121 tests.
- It says "one of them renders the record". Several tests use markdown_it.
- It says "Every test that expects a refusal also checks ... the expected reason, except command_line_exit_codes". That is false: ingestion_writes_only_the_record_and_provenance (lines 1755 to 1768) expects exits 3, 2 and 2 and checks only the codes.
- **Smallest fix:** remove or recompute the counts, and name the second exception.

**F4. Medium (R4, time-limit margin):**
- The correct script needs 3.3 to 3.6 s for the many_voice_tags input at load 7 to 12.
- A realistic list-based de-duplication, which grows with the square of the input, needed 13.2 s at load 10 to 12.
- The 10 s limit sits between those two with a thin margin on both sides. A quiet machine could let that slow version pass; a busier one could fail the correct script (INFERRED, not measured).
- **Smallest fix:** compare times at N and 4N inside one generous limit (say 60 s) and fail if the ratio is above about 8, instead of relying on a single absolute limit.

**F5. Low (R5, out-of-date or wrong text):**
- many_cues_holding_split_numbers_are_redacted_quickly says the reader "reads only four-digit utterance IDs". It is false: HEADING is `U-\d{4,}`, and a_record_of_10002 passes.
- hostile_text_cannot_stall_the_tool says the reader "merges every utterance after U-9999". False for the same reason.
- The KILL_MIDWAY comment says it "hooks os.replace and os.rename". It also hooks os.link, which is the call that is actually used.
- timestamps_use_one_stated_format says "planned SKILL.md 3", but section 3 exists.
- a_failure_at_any_write_step…'s docstring puts four sentences in quotes as SKILL.md wording. grep finds 0 of the 4 verbatim, for example "If the second move fails, the first file is removed."
- **Fix:** edit the text.

**F6. Low: the suite quietly assumes the system temp folder is outside the script's repository folder.**
- When it is not, 86 tests fail with a git message that blames the script (OBSERVED in my first reverse attempt).
- **Fix:** add one check in main(): if `tempfile.gettempdir()` is inside `INGEST.parents[2]`, stop with a setup message.

**F7. Low (R1, disclosed in the docstrings):**
- Some tests pin the script's own keys and wording: timestamp_format, the provenance key spellings, and refusal phrases such as "appeared while this run was writing" and "out of order".
- instruction_text_is_recorded_and_not_followed builds its expected record with the script's own `escape_md`.
- each_instruction_pattern_is_needed is named after the script's three regexes rather than a requirement. Its checks do fail when any one pattern is removed (OBSERVED).
- These are honest change detectors, not defects.

**F8. Low (R7):** hostile_text_cannot_stall_email_redaction's failure message gives only the actual first 60 characters and the length, not the expected text or the first difference. Fix: use the `expect_same` helper from hostile_text_cannot_stall_the_tool.

**F9. Low (R4):** rerun_at_a_later_time_writes_nothing uses random hash seeds, so it is not deterministic. A failure prints its seed, so it can be reproduced.
